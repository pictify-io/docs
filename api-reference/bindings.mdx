# Bindings

Bindings connect templates to external data sources, enabling automatic image generation when data changes. Perfect for dynamic dashboards, real-time stats, and automated social media images.

## How Bindings Work

1. **Create a binding** - Link a template to an external data URL
2. **Pictify fetches data** - Based on refresh policy, Pictify fetches your data
3. **Template renders** - Variables from the data are injected into the template
4. **Image updates** - The rendered image URL stays the same, content updates

```
[Your Data API] → [Binding] → [Template] → [Updated Image]
```

## Create Binding

Create a new binding.

<CodeGroup>
```bash cURL
curl -X POST https://api.pictify.io/bindings \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "templateId": "tmpl_github_card",
    "name": "GitHub Stats",
    "dataSource": {
      "type": "http",
      "url": "https://api.github.com/repos/your/repo",
      "method": "GET"
    },
    "mapping": {
      "repoName": "name",
      "stars": "stargazers_count",
      "forks": "forks_count",
      "description": "description"
    },
    "refreshPolicy": {
      "type": "ttl",
      "ttlSeconds": 3600
    },
    "outputConfig": {
      "format": "png",
      "quality": 90
    }
  }'
```

```typescript Node.js
const binding = await pictify.bindings.create({
  templateId: 'tmpl_github_card',
  name: 'GitHub Stats',
  dataSource: {
    type: 'http',
    url: 'https://api.github.com/repos/your/repo',
    method: 'GET'
  },
  mapping: {
    repoName: 'name',
    stars: 'stargazers_count',
    forks: 'forks_count',
    description: 'description'
  },
  refreshPolicy: {
    type: 'ttl',
    ttlSeconds: 3600  // 1 hour
  },
  outputConfig: {
    format: 'png',
    quality: 90
  }
});

// Use this URL in your README, website, etc.
console.log(`Render URL: ${binding.renderUrl}`);
```

```python Python
binding = pictify.bindings.create(
    template_id='tmpl_github_card',
    name='GitHub Stats',
    data_source={
        'type': 'http',
        'url': 'https://api.github.com/repos/your/repo',
        'method': 'GET'
    },
    mapping={
        'repoName': 'name',
        'stars': 'stargazers_count',
        'forks': 'forks_count',
        'description': 'description'
    },
    refresh_policy={
        'type': 'ttl',
        'ttl_seconds': 3600  # 1 hour
    },
    output_config={
        'format': 'png',
        'quality': 90
    }
)
```
</CodeGroup>

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `templateId` | string | Yes | Template UID to render |
| `name` | string | No | Binding name (max 255 chars) |
| `dataSource` | object | Yes | Data source configuration |
| `mapping` | object | Yes | Map API fields to template variables |
| `defaults` | object | No | Default values for missing fields |
| `refreshPolicy` | object | No | When and how to refresh data |
| `outputConfig` | object | No | Output image configuration |

### dataSource Object

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | string | Yes | `http`, `webhook`, or `static` |
| `url` | string | No | URL to fetch data from (required for `http`) |
| `method` | string | No | HTTP method: `GET` or `POST` (default: `GET`) |
| `headers` | object | No | Custom HTTP headers |
| `body` | any | No | Request body for POST requests |
| `credentials` | object | No | Authentication configuration |

### credentials Object

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | `api_key`, `bearer_token`, `basic_auth`, or `custom_header` |
| `value` | string | Token or API key value |
| `username` | string | Username for `basic_auth` |
| `headerName` | string | Header name for `custom_header` |

### refreshPolicy Object

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `type` | string | `ttl` | `ttl`, `etag`, `webhook`, or `manual` |
| `ttlSeconds` | integer | 300 | Cache duration (60-604800 seconds) |
| `onError` | string | `serve_stale` | `serve_stale`, `serve_error`, or `serve_default` |

### outputConfig Object

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `format` | string | `png` | `png`, `jpeg`, `webp`, or `pdf` |
| `quality` | integer | 90 | Image quality (1-100) |
| `width` | integer | - | Override template width |
| `height` | integer | - | Override template height |

## Update Binding

Update an existing binding.

<CodeGroup>
```bash cURL
curl -X PUT https://api.pictify.io/bindings/bind_abc123 \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "refreshPolicy": {
      "ttlSeconds": 1800
    },
    "status": "active"
  }'
```

```typescript Node.js
const binding = await pictify.bindings.update('bind_abc123', {
  refreshPolicy: {
    ttlSeconds: 1800  // 30 minutes
  },
  status: 'active'
});
```

```python Python
binding = pictify.bindings.update('bind_abc123',
    refresh_policy={'ttl_seconds': 1800},
    status='active'
)
```
</CodeGroup>

### Request Body

All fields are optional:

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | string | New binding name |
| `dataSource` | object | New data source configuration |
| `mapping` | object | New field mapping |
| `defaults` | object | New default values |
| `refreshPolicy` | object | New refresh policy |
| `outputConfig` | object | New output configuration |
| `status` | string | `active` or `paused` |

## Data Mapping

Map fields from your API response to template variables:

### Direct Mapping

```json
{
  "mapping": {
    "title": "name",
    "count": "stargazers_count"
  }
}
```

API Response:
```json
{ "name": "My Repo", "stargazers_count": 500 }
```

Template Variables:
```json
{ "title": "My Repo", "count": 500 }
```

### Nested Fields

Use dot notation for nested fields:

```json
{
  "mapping": {
    "userName": "user.name",
    "avatarUrl": "user.avatar_url"
  }
}
```

### Array Access

```json
{
  "mapping": {
    "firstItem": "items[0].name",
    "itemCount": "items.length"
  }
}
```

## Binding Status

| Status | Description |
|--------|-------------|
| `active` | Binding is active and refreshing |
| `paused` | Temporarily disabled |
| `error` | Failed to fetch data or render |

## Refresh Policy Types

| Type | Description |
|------|-------------|
| `ttl` | Refresh after time-to-live expires (default) |
| `etag` | Refresh when ETag changes |
| `webhook` | Refresh when webhook is triggered |
| `manual` | Only refresh when manually triggered |

## Examples

### GitHub Stats Badge

```typescript
const binding = await pictify.bindings.create({
  templateId: 'tmpl_github_badge',
  name: 'GitHub Stars',
  dataSource: {
    type: 'http',
    url: 'https://api.github.com/repos/owner/repo',
    method: 'GET'
  },
  mapping: {
    stars: 'stargazers_count',
    forks: 'forks_count',
    issues: 'open_issues_count'
  },
  refreshPolicy: {
    type: 'ttl',
    ttlSeconds: 3600  // Hourly
  }
});

```

### Authenticated API

```typescript
const binding = await pictify.bindings.create({
  templateId: 'tmpl_stats_card',
  name: 'Private Stats',
  dataSource: {
    type: 'http',
    url: 'https://your-api.com/stats',
    method: 'GET',

  }
});
```

## Webhooks for Bindings

Subscribe to binding events:

| Event | Description |
|-------|-------------|
| `binding.updated` | Binding successfully refreshed |
| `binding.failed` | Binding refresh failed |

```typescript
await pictify.webhooks.create({
  event: 'binding.updated',
  targetUrl: 'https://your-server.com/webhooks/binding',
  filters: {
    bindingId: 'bind_abc123'
  }
});
```

## Best Practices

1. **Set appropriate TTL** - Don't refresh more often than data changes
2. **Use defaults** - Provide fallback values for missing fields
3. **Handle errors gracefully** - Use `serve_stale` for critical images
4. **Monitor binding health** - Set up webhooks for `binding.failed` events
5. **Test before deploying** - Use the `/test` endpoint to validate your setup
