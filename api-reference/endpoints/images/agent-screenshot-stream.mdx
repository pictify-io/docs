title: Agent Screenshot Stream
api: POST https://api.pictify.io/image/agent-screenshot-stream
---

<Warning>
This endpoint uses Server-Sent Events (SSE) for real-time streaming. The API playground cannot test streaming responses — use cURL or an SDK instead.
</Warning>

Stream an AI-powered screenshot with real-time progress updates. The response is a `text/event-stream` that emits events as the AI processes the page.

## Authentication

Requires an API token via `Authorization: Bearer` header or `?token=` query parameter.

## Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `url` | string | Yes | URL to screenshot |
| `prompt` | string | No | AI instructions for the screenshot |
| `width` | integer | No | Output width in pixels (default: 1200) |
| `height` | integer | No | Output height in pixels (default: 630) |

## SSE Event Types

| Event | Description |
|-------|-------------|
| `connected` | Connection established |
| `step` | AI processing step (includes progress details) |
| `complete` | Screenshot generation complete |
| `saved` | Image saved and available at URL |
| `error` | An error occurred |

## Example

<CodeGroup>
```bash cURL
curl -N -X POST https://api.pictify.io/image/agent-screenshot-stream \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "prompt": "Screenshot the hero section"
  }'
```

```typescript Node.js
const response = await fetch('https://api.pictify.io/image/agent-screenshot-stream', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${apiKey}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    url: 'https://example.com',
    prompt: 'Screenshot the hero section'
  })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;

  const text = decoder.decode(value);
  for (const line of text.split('\n')) {
    if (line.startsWith('data: ')) {
      const data = JSON.parse(line.slice(6));
      console.log(data);
    }
  }
}
```

```python Python
import requests
import json

response = requests.post(
    'https://api.pictify.io/image/agent-screenshot-stream',
    headers={
        'Authorization': f'Bearer {api_key}',
        'Content-Type': 'application/json'
    },
    json={
        'url': 'https://example.com',
        'prompt': 'Screenshot the hero section'
    },
    stream=True
)

for line in response.iter_lines():
    if line:
        line = line.decode('utf-8')
        if line.startswith('data: '):
            data = json.loads(line[6:])
            print(data)
```
