# API Overview

The Pictify API is a RESTful JSON API for generating images, GIFs, and PDFs programmatically.

## Base URL

```
https://api.pictify.io
```

## Authentication

All requests require a Bearer token:

```bash
curl https://api.pictify.io/image \
  -H "Authorization: Bearer YOUR_API_KEY"
```

See [Authentication](/authentication) for details.

## Request Format

- Content-Type: `application/json`
- Request bodies are JSON
- Dates use ISO 8601 format

```bash
curl -X POST https://api.pictify.io/image \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "html": "<h1>Hello World</h1>",
    "width": 1200,
    "height": 630
  }'
```

## Response Format

Successful responses return JSON with relevant data:

```json
{
  "url": "https://cdn.pictify.io/renders/abc123.png",
  "id": "img_abc123",
  "width": 1200,
  "height": 630,
  "createdAt": "2026-01-29T10:30:00Z"
}
```

Error responses are plain JSON with a human-readable message under `message` or `error` (see [Error Handling](/api-reference/errors) for every shape):

```json
{
  "message": "Template not found"
}
```

## Rate Limits and Credits

Usage is governed by your plan's **monthly credits** — every render (image, GIF, PDF page, video) consumes credits, and generation endpoints return `402` when they run out. A small number of endpoints (unauthenticated public rendering, template previews) carry fixed per-minute rate limits and return `429`.

The API does not send `X-RateLimit-*` or `Retry-After` headers; on `429`, back off exponentially starting at a few seconds.

## Pagination

List endpoints return paginated results:

```bash
curl "https://api.pictify.io/templates?page=2&limit=20" \
  -H "Authorization: Bearer $API_KEY"
```

Response includes pagination metadata:

```json
{
  "templates": [...],
  "pagination": {
    "page": 2,
    "limit": 20,
    "total": 45,
    "totalPages": 3,
    "hasNext": true,
    "hasPrev": true
  }
}
```

## HTTP Status Codes

| Code | Description |
|------|-------------|
| 200 | Success |
| 201 | Created |
| 202 | Accepted (async operation started) |
| 400 | Bad Request (validation error) |
| 401 | Unauthorized (invalid API key) |
| 403 | Forbidden (access denied) |
| 404 | Not Found |
| 422 | Unprocessable Entity |
| 429 | Rate Limit Exceeded |
| 500 | Internal Server Error |

## Idempotency

POST requests can include an `Idempotency-Key` header for safe retries:

```bash
curl -X POST https://api.pictify.io/image \
  -H "Authorization: Bearer $API_KEY" \
  -H "Idempotency-Key: unique-request-id-123" \
  -H "Content-Type: application/json" \
  -d '{"html": "..."}'
```

The same key with the same request will return the cached response for 24 hours.

## Versioning

The API does not currently use URL-based versioning. All endpoints are accessed directly from the base URL. Breaking changes will be communicated in advance via release notes.
