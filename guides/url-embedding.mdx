# Embedding Dynamic Images

Embed Pictify-rendered images anywhere that accepts image URLs — `<img>` tags, emails, Open Graph meta tags, and more.

<Note>
For URL patterns, auth requirements, and caching behavior, see [URL Rendering Concept](/concepts/url-rendering).
</Note>

## Common Use Cases

### Open Graph Images

Generate dynamic OG images for social sharing:

```html
<meta property="og:image" content="https://api.pictify.io/r/tmpl_og.png?token=pk_live_...&title=My%20Blog%20Post&author=Jane" />
```

### Email Campaigns

Personalize email images per recipient:

```html
<img src="https://api.pictify.io/r/tmpl_email.png?token=pk_live_...&name=John&offer=20%25%20off" />
```

### Real-Time Dashboards

Display live data visualizations with bindings (no auth needed):

```html
<img src="https://api.pictify.io/b/bind_stats.png" alt="Weekly stats" />
```

### A/B Test Variants

Serve experiment variants automatically:

```html
<a href="https://api.pictify.io/s/email-banner-ctr/click">
  <img src="https://api.pictify.io/s/email-banner-ctr.png" alt="Special offer" />
</a>
```

### Markdown / README Badges

```markdown
![Status](https://api.pictify.io/b/bind_status.png)
```

## Best Practices

1. **URL-encode variable values** — spaces and special characters must be encoded
2. **Use bindings for data that changes frequently** — they auto-refresh without rebuilding URLs
3. **Set fallback images for experiments** — prevents broken images when experiments end
4. **Use WebP format** when possible for best file size and quality
5. **Cache-bust binding URLs** by appending `?_t=timestamp` when you need the latest version immediately
